Reference architecture and module contract

A shared contract avoids register clobbering and inconsistent battery updates when six people merge assembly code.

BOOT └─ Read PDR, MBC, IBC (Enter → 1, 15, 5) └─ Initialise charge = IBC; offline = false └─ MAIN EVENT LOOP ├─ Poll input (nonblocking) │ ├─ C n → charge + n │ ├─ S n → charge + 2n │ ├─ D n → charge + 2n │ ├─ T n → charge − 3n │ ├─ R → restore configured IBC │ ├─ Q → quit │ └─ bad → reject without command change └─ Simulated 1-second tick ├─ Normal online: subtract PDR ├─ Reset tick: no drain ├─ Offline: no drain └─ Print telemetry

Shared state

charge, PDR, MBC, IBC, elapsed, offline, reset_skip, command_buffer.

Never display charge below 0 or above MBC; when a requested charge increase exceeds MBC, show the capacity warning.

Procedure conventions

parse_command($a0=line) → $v0=letter, $v1=n. Invalid command → $v0=0.

parse_positive($a0=text) → positive integer in $v0, otherwise zero.

Preserve modified $s0–$s7 and $ra in called procedures; treat $t0–$t9 as caller-clobbered.

Timing pitfall: normal blocking MARS console input does not let battery charge decay while the user is idle. A nonblocking input approach (such as MARS Keyboard and Display MMIO with a clock) is needed for genuine idle-time drain. The sample's timestamps are a controlled scenario; do not assume they arise from typing commands immediately.
